# E-Commerce Customer Segmentation using RFM and K-Means

A customer segmentation project that uses **RFM (Recency, Frequency, Monetary) analysis** and **K-Means clustering** to identify meaningful customer groups and develop targeted marketing strategies.

## Project Overview

Customer segmentation helps businesses understand different types of customers based on their purchasing behavior.

This project analyzes the **Online Retail** transactional dataset and applies an end-to-end machine learning workflow:

1. Data cleaning and preprocessing
2. RFM feature engineering
3. Log transformation and standardization
4. K-Means clustering
5. Elbow Method and Silhouette Score evaluation
6. Customer persona creation
7. Marketing strategy generation
8. Data visualization

## Dataset

The project uses the **Online Retail dataset** containing e-commerce transactions.

The original dataset contains:

* **541,909 transactions**
* **8 original attributes**
* Transaction information such as invoice number, product, quantity, price, customer, date, and country

After data cleaning:

* **397,884 valid transactions**
* **4,338 unique customers**

The raw Excel dataset is excluded from Git tracking because of its size.

## RFM Analysis

RFM analysis represents customer purchasing behavior using three metrics.

| Metric    | Description                                       |
| --------- | ------------------------------------------------- |
| Recency   | Number of days since the customer's last purchase |
| Frequency | Number of unique orders made by the customer      |
| Monetary  | Total transaction value generated by the customer |

Before clustering, the RFM features are log-transformed and standardized to reduce skewness and make the features comparable.

## K-Means Clustering

Different values of K from **2 to 10** were evaluated using:

* Elbow Method
* Silhouette Score

Although K=2 produced the highest Silhouette Score, **K=4** was selected because it provided more actionable and interpretable customer segments for marketing purposes.

The final model uses:

```text
K = 4
Random State = 42
n_init = 10
```

## Customer Segments

The final four customer personas are:

| Persona                   | Characteristics                                 | Recommended Strategy                            |
| ------------------------- | ----------------------------------------------- | ----------------------------------------------- |
| VIP / Loyal Customers     | Recent purchases, high frequency, high spending | VIP rewards, exclusive offers, loyalty benefits |
| New / Potential Customers | Recent customers with relatively few purchases  | Welcome offers and second-purchase discounts    |
| Regular Customers         | Moderate recency, frequency, and spending       | Cross-selling and personalized recommendations  |
| At-Risk / Lost Customers  | Long time since purchase and low activity       | Win-back campaigns and re-engagement offers     |

## Key Insights

The segmentation shows clear differences in customer behavior.

**VIP / Loyal Customers** generate the highest average monetary value and make purchases frequently. They should be retained through loyalty programs and exclusive benefits.

**New / Potential Customers** have recently purchased but have relatively low purchase frequency. Encouraging a second purchase can help convert them into regular customers.

**Regular Customers** demonstrate moderate purchasing behavior and represent an opportunity for cross-selling and personalized recommendations.

**At-Risk / Lost Customers** have the longest average period since their last purchase and the lowest purchase frequency. They are suitable targets for win-back and re-engagement campaigns.

## Conclusion

This project demonstrates how RFM analysis and unsupervised machine learning can transform raw e-commerce transaction data into actionable customer segments.

The resulting customer personas provide a practical foundation for targeted marketing, customer retention, loyalty programs, and personalized recommendations.
